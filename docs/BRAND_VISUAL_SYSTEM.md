## 4. 響應式排版與無障礙設計鐵則（Layout & Accessibility Rules）

1. **手機版 (`9:16` / `< 820px`) 頂部工具列折疊規範**：
   - 嚴禁頂部工具列換行遮擋「早安，總監」與 3 張核心儀表板卡片。
   - 手機端 `.topbar` 強制 `flex: 0 0 auto; flex-wrap: nowrap; min-height: 52px;`，所有進階工具統一收納於 **「`☰ 工具列`」** 跳出式通知視窗。
2. **角色對話氣泡自適應規範**：
   - 地圖角色頭頂氣泡（`.speech-bubble`）與視窗內 RPG 對話框（`.rpg-dialogue-bubble-adaptive`）須隨角色台詞字數自動伸縮（`min-width: 68px` 至 `max-width: 188px`），嚴禁文字截斷或前後角色重疊。
3. **頭像容器邊界防護**：
   - 所有 Emoji、像素畫布（`MascotAvatar`）與使用者上傳圖片（Data URL / 外部圖片）一律包裹於 `.avatar-clip-box`（`overflow: hidden; object-fit: cover`），確保絕不超出頭像外框。
4. **極簡訊號原則**：
   - 移除冗餘灰色說明副標題，僅保留必要之狀態燈號（`● 工作中`、`● 休息`、`● 需協助`）與即時數字徽章。
